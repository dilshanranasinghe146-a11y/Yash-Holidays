# Yash Holidays Web Application

Official website for **Yash Holidays Pvt Ltd** (276/E, Dehiwala Road, Boralesgamuwa, Sri Lanka).

## Features
- **4 Dedicated Tabs**:
  - **Home & Outbound Tours**: Interactive destination switcher across 8 signature markets (Bali, Thailand, Malaysia, Singapore, Vietnam, Maldives, India, Azerbaijan) with vertical timeline itineraries, included services, and custom package builder.
  - **Visa Services**: Complete checklist, validity, processing times, and WhatsApp consultation for 10 countries (Canada, New Zealand, UK, USA, Malaysia, Thailand, Vietnam, India, China, Japan).
  - **Air Tickets**: Global airfare inquiry form, airline partners, baggage allowances, and flight comparison table for major routes from Colombo (CMB).
  - **About Us**: Official company profile, metrics, office address, and direct hotlines.
- **Customized Tour Package Builder**: Configurable duration, pax, hotel tier, add-ons (flights, visa, insurance), and custom notes prefilled directly into WhatsApp.
- **Live Google Map**: Embedded interactive map showing office location in Boralesgamuwa.
- **Direct Hotlines & WhatsApp**: Instant quote buttons linked to `011 231 2093` and `+94 77 584 1144`.

## Available Scripts

In the project directory, you can run:

### `npm run dev`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`
Builds the app for production to the `dist` folder.

### `npm run preview`
Locally preview the production build.
